# 低成本买量创意方法

把来源方法转成制作选择。以下游戏例子为应用示范，涉及玩法和福利时仍需用户确认。

## 拆解参考的吸引机制

区分吸引停留的刺激、推动故事的目标、体现卖点的证据、促使行动的理由。改编时写清保留的吸引机制，以及重新拍摄、录制或设计的关键画面。

## 人设、场景、情节扩展

| 维度 | 可调整项 | 手游应用示范 |
|---|---|---|
| 讲述视角 | 当事人、访谈、调查、对话、演示 | 将单人讲装备改为队友质疑后，现场演示来源 |
| 人物 | 身份、关系、经历、即时目标、行为习惯 | 管账弟子与只想闭关的师尊因修缮开支产生冲突 |
| 场景 | 时间、天气、空间用途、标识物、动线 | 用修缮中的宗门大堂，账册与破损牌匾参与剧情 |
| 情节 | 提问、误解、任务、挑战、发现、反转 | 质疑、尝试、操作、反馈构成因果链 |
| 视觉 | 景别、构图、前后景、动效、UI 层级 | 围绕装备获得过程安排角色动作与信息出现顺序 |

选择服务核心卖点的少数变量，不机械更换全部设定。用户锁定人物或机位时，在未锁定项中创新。

## 老梗新编

保留一个熟悉的矛盾，重写事件条件、人物动机与解决方式。针对装备来源疑问，可设计询问、误会或挑战，每个方向都配对应的新画面和卖点证据，避免只换宣传词人称。

区分演出剧情与真实玩家经历；不要编造玩家证言。

## 降低实拍成本

- 按演员能力把长段正面背稿改为短句对话、侧面反应、手部操作或旁白配演示。
- 提前准备少量有辨识度的桌面物件、服饰或前景，结合新的行动拍摄。
- 同场记录多个机位，补拍关键动作前后、表情反应、道具细节和必要空镜。
- 为版本设计实际需要的新镜头。增加原片是为了扩展表达，不承诺一次拍摄产出多条独立首发。

## 游戏录屏和混剪

- 用真实可用玩法支撑游戏承诺，或把演出画面明确作为创意表现。
- 用目标出现、操作尝试、反馈结果组织信息，保留操作的识别时间。
- 讲获得过程时展示获得过程，讲养成变化时展示有依据的前后变化。
- 为新事件重拍或重录关键镜头，控制少数旧高光的反复使用。
- 让镜头和口播共同推进故事，避免以密集转场遮盖关键动作。

## 动效、UI 与静态设计

围绕卖点安排视觉焦点，再设计布局、尺度、层级、色彩与运动顺序。避免同时堆放大量发光、粒子和弹窗。

描述动效时明确元素从何处出现、经过哪里、速度怎样变化、最后停在哪里。制作 UI 时说明边界、留白、透明区域和文字层；按需要选择可编辑文字或后期叠字。

只在用户要求时生成实际素材，不能把提示词当作已经生成的图片或视频。

## 游戏卖点的证据选择

| 已确认的卖点 | 可见证据 | 避免无依据添加 |
|---|---|---|
| 装备获取 | 获得界面、战斗、掉落过程 | 固定极品掉率、人人必得 |
| 宗门建造 | 操作与建筑阶段变化 | 未确认的自由建造玩法 |
| 角色养成 | 可验证的等级、外观或技能变化 | 免费满级、瞬间毕业 |
| 活动福利 | 实际礼包、入口、领取条件 | 过期兑换码、无限领取、虚构数额 |
| 轻量玩法 | 一次操作和可理解的结果 | 产品没有的交互和收益 |

## 选择方案

比较目标人群、可见卖点、第一眼画面、主要制作成本、资产依赖和待验证问题。按用户预算与已有素材选择可执行方案，避免只按画面华丽程度排序。

评估创新时只对已知参考逐镜说明变化，明确未知对比范围，不输出平台级相似率或首发概率。
